# sources

One file per work package: `wpN-name.md`, built from `_TEMPLATE.md`.

## Rules

- **Never invent a source.** A reference that does not exist can fail the project. Mark anything not opened and checked as "to verify".
- Use Harvard (TUS style) for references.
- Mark forum posts and blogs as build-only. Find official documentation or a peer-reviewed source before citing them in the dissertation.
- Every file needs a "Changes the plan" section. Write "None" if nothing changes.
- When a source contradicts the plan: record it under "Changes the plan", update `../PLAN.md`, then add a dated line under "Decisions already made" in `../../CLAUDE.md`.
- Keep the "Used for" column to one or two sentences stating what the source established.
