# prompts

Self-contained prompts, each run in a fresh conversation to produce dissertation material.

## Rules

- Each file has a short intro (what it produces and where it is used), then the prompt in a fenced `text` block.
- A prompt must stand alone: include the project title, scope, research questions and any constraints it needs. Do not rely on other files being attached.
- Keep prompts in step with `../PLAN.md`. If the plan changes, check every prompt for stale scope.
- Prompts must force traceability (weak point, control, test) and honest residual risk, so the dissertation does not overclaim.
- Never put a real secret in a prompt.
